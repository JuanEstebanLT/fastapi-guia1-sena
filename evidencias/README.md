## Criterios de organización

- Los documentos y videos del **índice general** se almacenan exclusivamente dentro de `evidencias/guia_XX/`, nunca sueltos en este directorio.
- Cada actividad también conserva su material en `guia_XX/evidencias/`, de acuerdo con el esquema de entrega del curso.
- Los archivos se identifican con nombres descriptivos; los enlaces se incluyen únicamente cuando el archivo existe.
- Los documentos y videos de futuras guías se añaden al momento de realizar cada actividad.
- Para la Guía 2, el documento PDF ya está disponible en ambas ubicaciones; el video de sustentación también está publicado en ambas ubicaciones.
