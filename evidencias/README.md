# Evidencias académicas — FastAPI SENA

Este directorio reúne las evidencias de las guías del curso de FastAPI del programa **Análisis y Desarrollo de Software (ADSO)** del SENA. Cada guía también conserva su propia carpeta de evidencias, de forma que el material puede consultarse desde el índice general o desde la actividad correspondiente.

## Criterio de organización

- La carpeta general contiene una copia de los archivos de entrega de cada guía.
- La carpeta `guia_XX/evidencias/` conserva los mismos documentos y videos correspondientes a esa actividad.
- El informe de cada guía se publica con un nombre descriptivo y, cuando corresponda, con la versión documental aprobada.
- Solo se publican capturas, documentos y videos reales; los trabajos futuros permanecen identificados como pendientes.
- Los enlaces de los videos externos se agregan únicamente cuando la grabación esté publicada.
